# ziweidoushu（紫微鉴）

准确、可解释、隐私优先的紫微斗数排盘工具。移动端优先的纯前端 Web 应用（React 18 + TypeScript + Vite），排盘 100% 在浏览器内完成，**出生数据不上传**。

## 特性

- **排得准**：真太阳时校正（盘面标明校正分钟数）、农历闰月、早子/晚子换日策略可选
- **看得懂**：点开任一宫位可下钻星曜、三方四正、四化影响与推导依据；自动识别 20 条常见格局
- **时间维度**：本命·大限 / 流年切换，支持双盘对照
- **够私密**：无账号、无后端，数据只在本机处理；支持离线使用（PWA）
- **盘库与分享**：IndexedDB 本地保存（仅存排盘参数），链接分享（不含姓名与备注），导出图片与 A4 打印

## 快速开始

```bash
npm install
npm run dev       # 开发（Vite）
npm run build     # 类型检查 + 生产构建
npm run preview   # 预览构建产物
npm run test      # 单元测试（引擎 / 黄金样本 / 分享编码）
```

## 目录结构

```
src/
├─ engine/        排盘引擎（纯 TS，零 UI 依赖，含黄金样本回归）
├─ components/    十二宫格、宫位详情、术语解释、引导等 UI
├─ pages/         首页表单、命盘、盘库、合盘、设置
├─ library/       持久化（IndexedDB）、分享编码、导出图
├─ store/         Zustand（当前盘 / 盘库）
└─ styles/        设计令牌（tokens.css 为唯一允许出现色值的文件）
```
